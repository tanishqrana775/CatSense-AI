5. HOW TO EDIT COLORS
================================================================================

STEP 1: Open front_end/static/styles/main.css

STEP 2: Find the :root {} section (lines 10-50)

STEP 3: Change any CSS variable value

EXAMPLE: Change primary brand color from pink to blue
BEFORE:
--c-primary: #FF6B9D;

AFTER:
--c-primary: #3B82F6;

EXAMPLE: Change background from dark to light
BEFORE:
--c-bg-app: #0f0f1e;

AFTER:
--c-bg-app: #ffffff;

EXAMPLE: Change cat eye color from gold to green
BEFORE:
--c-cat-eye: #FFD700;

AFTER:
--c-cat-eye: #10B981;

IMPORTANT: All colors use CSS variables, so changing them in :root {}
will update the entire site automatically!

7. HOW TO ADD NEW FEATURES
================================================================================

ADD NEW PAGE:
1. Create new HTML file in front_end/templates/
2. Extend base.html or main.html
3. Add route in app.py
4. Add navigation link in navbar

EXAMPLE:
# In app.py
@app.route('/about')
def about():
    return render_template('about.html')

# In front_end/templates/about.html
{% extends "base.html" %}
{% block content %}
<h1>About MeowMind</h1>
{% endblock %}

ADD NEW EMOTION:
1. Add color variable in main.css :root {}
2. Add emotion badge style in CSS
3. Update predictor.py to return new emotion
4. Update metrics.html emotion guide

8. DATABASE STRUCTURE
================================================================================

FILE: database/database_logic.py

MODELS:

User Model:
- id (Integer, Primary Key)
- name (String, default='Cat Lover')
- email (String, unique)
- password_hash (String)
- predictions (Relationship to Prediction)

Prediction Model:
- id (Integer, Primary Key)
- user_id (Integer, Foreign Key to User)
- file_type (String: 'image' or 'audio')
- filename (String)
- prediction_result (String: emotion name)
- confidence (Float, optional)
- timestamp (DateTime, auto-generated)

QUERY EXAMPLES:

Get all predictions for a user:
predictions = Prediction.query.filter_by(user_id=user_id).all()

Get recent predictions:
recent = Prediction.query.filter_by(user_id=user_id)\
    .order_by(Prediction.timestamp.desc()).limit(10).all()

Count predictions by emotion:
from collections import Counter
emotions = Counter(p.prediction_result for p in predictions)

================================================================================
TROUBLESHOOTING
================================================================================

ISSUE: Colors not updating
SOLUTION: Clear browser cache (Ctrl+Shift+R or Cmd+Shift+R)

ISSUE: Video not playing
SOLUTION: Check video format (MP4 H.264), check file path, check Flask route

ISSUE: Layout broken on mobile
SOLUTION: Check responsive CSS (@media queries), test on real devices

ISSUE: Buttons not clickable
SOLUTION: Check z-index, check if element is covered by another

ISSUE: Database errors
SOLUTION: Delete cat_emotion.db and restart app to recreate database

ISSUE: AI predictions failing
SOLUTION: Check model files exist, check file upload path, check logs

ISSUE: Flash messages not showing
SOLUTION: Check base.html has flash message block, check Flask flash() calls

ISSUE: CSS changes not visible
SOLUTION: Hard refresh browser, check CSS file path, check for syntax errors
